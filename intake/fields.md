# 収集フォームの項目一覧

`scripts/intake/fields.mjs` から自動生成されています（`npm run intake:template --force`）。

## フォームA「会社基本情報」

1社につき1回だけ提出します。

### 1. 会社の基本情報

サイト全体のヘッダー・フッター・構造化データに使われます。

| 質問 | 形式 | 必須 | 補足 |
|------|------|------|------|
| 会社名（正式名称） | 記述式 | 必須 | 例: 株式会社ネオキャリア |
| サイト上の呼称 | 記述式 | 必須 | ロゴ横に出る表記。例: NEO CAREER |
| 採用年度 | 記述式 | 必須 | 例: 2027 |
| PURPOSE（採用サイトの軸になる一文） | 記述式 | 必須 | 例: 人と本気で向き合い、未来を切り拓く。 |
| 郵便番号 | 記述式 |  | ハイフンあり。例: 160-0023 |
| 都道府県 | 記述式 |  | 例: 東京都 |
| 市区町村 | 記述式 |  | 例: 新宿区 |
| 番地・建物名 | 記述式 |  | 例: 西新宿1-22-2 新宿サンエービル |
| コーポレートサイトのURL | 記述式 |  | フッターからリンクします。不要なら空欄。 |
| コピーライト表記 | 記述式 |  | 例: © neo career |

### 2. デザイン

ブランドカラーは16進数（#から始まる6桁）で入力してください。ボタンのホバー色とタグの淡色は自動生成されます。

| 質問 | 形式 | 必須 | 補足 |
|------|------|------|------|
| メインカラー | 記述式 |  | ボタン・見出しラベルの色。例: #1a5fd0 |
| 濃色背景の色 | 記述式 |  | ヒーロー／PURPOSE／エントリーの背景。例: #0a1f3d |
| ロゴ／シンボル画像 | 画像 |  | 画像の公開URL、または public/images/ に置くファイル名（例: hero-jobs.jpg）を入力してください。 |

### 3. 配信URL

3サイトはそれぞれ別のURLで配信されます。canonical・OGP・構造化データの基準になります。

| 質問 | 形式 | 必須 | 補足 |
|------|------|------|------|
| 「仕事を知る」サイトのURL | 記述式 |  | 例: https://example-jobs.pages.dev |
| 「人を知る」サイトのURL | 記述式 |  | 例: https://example-people.pages.dev |
| 「選考を知る」サイトのURL | 記述式 |  | 例: https://example-faq.pages.dev |

| 【仕事】事業セクションの見出し | 記述式 |  | 例: 結局、何をやっている会社？ |

| 【仕事】事業セクションの補足 | 段落 |  | セクション下部の小さな一文。不要なら空欄。 |
| 【仕事】数字セクションの見出し | 記述式 |  | 例: 数字で見る◯◯ |
| 【仕事】数字セクションのリード文 | 段落 |  |  |

| 【仕事】数字セクションの画像 | 画像 |  | 画像の公開URL、または public/images/ に置くファイル名（例: hero-jobs.jpg）を入力してください。 |
| 【仕事】数字セクションの画像の説明 | 記述式 |  | 例: ◯◯のオフィス |

| 【仕事】職種セクションのリード文 | 段落 |  |  |
| 【仕事】比較表の見出し | 記述式 |  | 例: 職種を横に並べて比べる。比較表が不要なら空欄。 |
| 【仕事】比較表のリード文 | 段落 |  |  |

## フォームB「コンテンツ登録」

1件につき1回、必要な数だけ繰り返し提出します。「登録する内容」で入力欄が切り替わります。
「表示順」に数字を入れると並び順を指定できます（空欄なら送信順）。

### 事業

「仕事を知る」ページの事業カードになります。3件程度を推奨します。

| 質問 | 形式 | 必須 | 補足 |
|------|------|------|------|
| 【事業】事業名 | 記述式 | 必須 | 例: 採用支援 |
| 【事業】英語表記 | 記述式 | 必須 | カード内に小さく出ます。例: Recruitment |
| 【事業】説明文 | 段落 | 必須 | 3行程度で。 |
| 【事業】特徴タグ | 段落（1行1件） |  | 1行に1件ずつ、改行区切りで入力してください。3件程度を推奨。例: RPO |
| 【事業】画像 | 画像 |  | 画像の公開URL、または public/images/ に置くファイル名（例: hero-jobs.jpg）を入力してください。 |

### 職種

「仕事を知る」ページの職種カードになります。登録した順が比較表の列の順になります。

| 質問 | 形式 | 必須 | 補足 |
|------|------|------|------|
| 【職種】職種名 | 記述式 | 必須 | 例: 法人営業 |
| 【職種】英語表記 | 記述式 | 必須 | 例: B2B Sales |
| 【職種】キャッチコピー | 記述式 | 必須 | 例: 企業の採用課題を、根っこから解く。 |
| 【職種】仕事内容 | 段落 | 必須 | 3行程度で。 |
| 【職種】1日の流れ | 段落（1行1件） |  | 1行に「時刻 \| 内容」の形式で、改行区切りで入力してください。例: 09:30 \| チーム朝会・当日の商談準備 |
| 【職種】向いている人 | 段落（1行1件） |  | 1行に1件ずつ、改行区切りで入力してください。3件程度を推奨。例: 人と話すのが好き |
| 【職種】画像 | 画像 |  | 画像の公開URL、または public/images/ に置くファイル名（例: hero-jobs.jpg）を入力してください。 |
